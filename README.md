🏏 IPL Dashboard (2008-2022) 📊
Project Overview:
This Power BI IPL Dashboard provides comprehensive insights into the Indian Premier League seasons from 2008 to 2022. The dashboard offers an interactive analysis of key metrics, team performances, player statistics, and match outcomes, delivering a detailed view of the IPL's history and trends.

🔑 Key Problem Statements Addressed:
🏆 Title Winners: Displays the title winners for each season.
🧢 Orange Cap & Purple Cap Winners: Highlights the leading run-scorer (Orange Cap) and top wicket-taker (Purple Cap) of every season.
💥 Tournament 6’s and 4’s: Shows the total number of sixes and fours hit in each season.
⚾ Batting and Bowling Stats: Filter by batsman or bowler to see their detailed performance.
🎯 Winning Percentage by Toss Decision: Analyzes how toss decisions impact match results.
🏟️ Matches Won by Venue: Tracks which teams perform best at different venues.
🏅 Total Wins by Team in a Season: Summarizes the number of matches won by each team every season.
🏏 Matches Won Based on Result Type: Breaks down match wins by runs, wickets, and other result types.

🛠️ Skills Gained:
Advanced DAX Functions: Applied complex calculations for winning percentages and player stats.
Data Modeling: Cleaned and structured IPL datasets for accurate insights.
Interactive Filters: Enabled dynamic filtering for batting and bowling stats, making data exploration easy.
IPL Insights: Unlocked historical stats and trends across the IPL's journey from 2008 to 2022.
This dashboard is perfect for IPL enthusiasts, sports analysts, and strategists who want to explore IPL statistics in a visual, interactive format. Whether you're a fan or a professional, this tool brings valuable insights to the table! 📈🏏
